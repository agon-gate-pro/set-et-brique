# Récap de la semaine 46 (9 au 15 novembre 2026)

Base du point de fin de semaine avec Madus et Marion. Le détail technique est dans `FONCTIONNEMENT.md`, le journal complet dans `AVANCEMENT.md`.

## 1. Ce qui a changé sur le site

### Pour les clients

- **Pastille « Dernière chance »** avec un petit trèfle vert sur les sets bientôt retirés (9 novembre), dans le catalogue et sur la fiche du set. Ces sets passent juste après les coups de cœur. Un set peut avoir les deux pastilles.
- **« Indisponible »** remplace « En réparation » sur les sets qu'on ne peut pas louer en ce moment (9 novembre).

### Pour les gérants

- Nouvelle case **« Dernière chance »** dans la fiche d'un set, sous « Coup de cœur ». Pas de date : le set reste réservable. Pour le retirer, passer le set en « Archivé » : la case se décoche toute seule.
- Dans la **liste des sets**, les pastilles « Coup de cœur » et « Dernière chance » s'affichent sous le statut.
- La page **Ordre du catalogue** a maintenant un groupe « Dernière chance » entre les coups de cœur et les autres sets.
- Le statut « En réparation » d'un exemplaire s'appelle aussi « Indisponible » dans la fiche du set.
