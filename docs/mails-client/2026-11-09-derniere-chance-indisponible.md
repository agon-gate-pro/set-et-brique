Suite à vos réponses, les modifications sont en ligne sur le site.

1. Les sets « Dernière chance 🍀 »

Dans la fiche d'un set (espace de gestion, Sets, Modifier), une nouvelle case « Dernière chance » se trouve juste sous « Coup de cœur ». Quand elle est cochée :

image.png

une pastille blanche « Dernière chance » avec un petit trèfle vert s'affiche sur la photo du set dans le catalogue, et sur la page du set ;

image.png

le set remonte en tête du catalogue, juste après les coups de cœur.

Comme vous l'avez souhaité, il n'y a pas de date : le set reste réservable normalement. Quand vous décidez de le retirer, passez-le en « Archivé » dans sa fiche, comme d'habitude. La case « Dernière chance » se décoche alors toute seule, donc si le set revient un jour, il ne réapparaîtra pas avec la pastille.

Un set peut être à la fois coup de cœur et dernière chance : il affiche alors les deux pastilles.

image.png

Dans la liste des sets de l'espace de gestion, ces pastilles apparaissent aussi sous « Publié ». Vous voyez d'un coup d'œil quels sets sont cochés.

image.png

La page « Ordre du catalogue » a maintenant un groupe « Dernière chance », entre les coups de cœur et les autres sets. Vous pouvez y régler leur ordre comme pour les autres.

image.png

2. « Indisponible » à la place de « En réparation »

Un set qu'on ne peut pas louer en ce moment (comme la borne) affiche maintenant « Indisponible » pour les clients. Dans la fiche du set, le statut d'un exemplaire s'appelle aussi « Indisponible ». Il s'utilise comme avant : choisissez « Indisponible » pour bloquer le set le temps d'un souci, et « Disponible » quand il est de nouveau prêt.
